# 系統環境變數與 Script Properties 設定範本
# 請在 Google Apps Script「專案設定」->「指令碼屬性 (Script Properties)」中設定以下值：

LINE_CHANNEL_ACCESS_TOKEN=你的_LINE_CHANNEL_ACCESS_TOKEN
LINE_RELAY_SECRET=自訂的轉發密鑰（與_Cloudflare_Worker_保持一致）
GEMINI_API_KEY=你的_GOOGLE_GEMINI_API_KEY
BOOKING_WEB_URL=你的_GAS_網頁應用程式部屬網址

# Cloudflare Worker 環境變數 (Secrets / Variables)：
# LINE_CHANNEL_SECRET=你的_LINE_CHANNEL_SECRET
# GAS_RELAY_SECRET=與_GAS_指令碼屬性中相同的轉發密鑰
# GAS_WEBHOOK_URL=你的_GAS_網頁應用程式網址_(/exec)
